# Contributing

Thank you for your interest in contributing to this project!

## Rules

* Create a new branch for each change.
* Write clear commit messages.
* Keep your code clean and readable.
* Test your changes before submitting them.
* Clearly describe your changes in the Pull Request.
* Respect the codebase and other contributors.

## Pull Requests

Before creating a Pull Request, make sure that:

* [ ] The project works correctly.
* [ ] Your changes are complete.
* [ ] You have tested your code.
* [ ] You have clearly explained what you changed.

Thank you for contributing! ❤️
